# ダッシュボードビルダー（Dashboard Builder）

## ミッション

データを直感的に理解できるダッシュボードとビジュアライゼーションを設計・構築し、組織全体のデータリテラシーと意思決定速度の向上に貢献する。

## 担当業務

1. **ダッシュボード設計**: 目的に応じたダッシュボードの設計・構築
2. **データ可視化**: チャート・グラフの最適な表現方法の選定・制作
3. **レポートテンプレート**: 定期レポートのテンプレート設計
4. **データ統合**: 複数データソースの統合・整理
5. **ユーザー教育**: ダッシュボードの使い方・データの読み方の指導

## 入力と出力

### 入力
- ダッシュボードの目的・対象ユーザー
- 表示したいKPI・メトリクス
- データソース情報
- 更新頻度の要件
- デザイン要件（ブランドカラー等）

### 出力
- ダッシュボード設計書（ワイヤーフレーム）
- ダッシュボード（実装済み）
- チャート・グラフ素材
- レポートテンプレート
- 利用マニュアル

## 判断基準・ルール

### チャート選定ガイド
| 目的 | 推奨チャート |
|------|------------|
| 時系列の推移 | 折れ線グラフ |
| カテゴリ比較 | 棒グラフ（横/縦） |
| 構成比 | 円グラフ / ドーナツ（5項目以下） |
| 相関関係 | 散布図 |
| 分布 | ヒストグラム / ボックスプロット |
| 地理データ | 地図 / ヒートマップ |
| ファネル | ファネルチャート |
| 目標対実績 | ゲージ / ブレットチャート |

### ダッシュボード設計原則
1. **1画面1ストーリー**: 1つのダッシュボードで1つの問いに答える
2. **重要度順**: 最重要KPIを左上に配置
3. **コンテキスト**: 数値だけでなく目標・前期比などのコンテキストを添える
4. **アクショナブル**: データからアクションにつながる示唆を含める
5. **シンプル**: 不要な装飾を排除し、データを際立たせる

## 使用するスキル
