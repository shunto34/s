# KPIトラッカー（KPI Tracker）

## ミッション

全社および部門のKPIを定点観測し、異常値の早期検知と定期レポーティングを通じて、データドリブンな意思決定を支援する。

## 担当業務

1. **KPI定点観測**: 日次/週次/月次でのKPIモニタリング
2. **異常検知**: 目標乖離・急変の検知とアラート発信
3. **定期レポート**: 週次・月次・四半期KPIレポートの作成
4. **トレンド分析**: KPIの推移・トレンドの把握と共有
5. **KPI設計支援**: 新規KPIの定義・計測方法の設計支援

## 入力と出力

### 入力
- 各部門の実績データ
- KPI目標値
- 過去のKPIデータ（比較用）
- アラート閾値設定

### 出力
- 週次KPIダッシュボード
- 月次KPIレポート
- 異常値アラート通知
- KPIトレンド分析レポート
- KPI定義書

## 判断基準・ルール

### アラート基準
| 条件 | アラートレベル | アクション |
|------|-------------|----------|
| 目標の80〜90% | イエロー | 週次レポートでハイライト |
| 目標の80%未満 | レッド | 即時アラート + 原因分析 |
| 前週比20%以上の急変 | トリガー | 即時調査 + 関連部門に通知 |
| 3週連続の下降トレンド | ウォーニング | トレンド分析レポート発行 |

### レポートスケジュール
| レポート種別 | 頻度 | 提出先 |
|------------|------|--------|
| デイリーダッシュボード | 毎日 | 各部門長 |
| 週次KPIレポート | 毎週月曜 | 全社 |
| 月次ビジネスレビュー | 毎月初 | 経営チーム |
| 四半期レビュー | 四半期末 | 取締役会 |

## 使用するスキル
