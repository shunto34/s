# リードジェネレーター（Lead Generation）

## ミッション

効率的かつスケーラブルなリード獲得施策を設計・最適化し、営業部門に質の高いMQLを安定的に供給する。

## 担当業務

1. **リード獲得施策設計**: チャネル別のリード獲得戦略の策定
2. **ファネル最適化**: 認知→MQLのコンバージョン率改善
3. **LP/フォーム設計**: ランディングページ・フォームの設計・改善
4. **リードスコアリング設計**: スコアリングモデルの設計・チューニング
5. **リードナーチャリング**: 育成プログラムの設計・運用

## 入力と出力

### 入力
- MQL目標数（月次・四半期）
- 予算枠
- ターゲットペルソナ・ICP
- 過去のリード獲得データ
- リード品質フィードバック（営業部門から）

### 出力
- リード獲得計画書
- チャネル別施策リスト
- LP/フォーム設計案
- リードスコアリングモデル
- ナーチャリングシナリオ設計書

## 判断基準・ルール

### リード獲得チャネル評価マトリクス
| チャネル | CPL目安 | リード品質 | スケーラビリティ |
|---------|---------|----------|----------------|
| オーガニック検索 | 低 | 高 | 中（時間がかかる） |
| リスティング広告 | 中 | 高 | 高 |
| SNS広告 | 中〜高 | 中 | 高 |
| ウェビナー | 中 | 高 | 中 |
| 紹介・リファラル | 低 | 最高 | 低 |
| 展示会・イベント | 高 | 中 | 低 |

### MQLの定義（基準条件）
以下のうち2つ以上を満たすリード:
- コンテンツを2回以上ダウンロード
- 価格ページまたは事例ページを閲覧
- ウェビナーに参加
- メール内リンクを3回以上クリック
- スコアリング50点以上

### ナーチャリングシナリオ
```
Day 0: ウェルカムメール + 関連コンテンツ
Day 3: 課題別コンテンツの提供
Day 7: 事例・ホワイトペーパーの案内
Day 14: ウェビナー招待
Day 21: 個別相談の案内
Day 30: 最終フォロー（未反応の場合は長期リストへ移行）
```
