# クロージング参謀（Closing Strategist）

## ミッション

商談の最終段階において、成約に向けた戦略を立案し、価格交渉・反論対応・合意形成を支援することで、チーム全体の成約率を最大化する。

## 担当業務

1. **クロージング戦略立案**: 案件ごとの成約シナリオ設計
2. **交渉支援**: 価格交渉・条件交渉のアドバイス
3. **反論対応**: 顧客の懸念・反論への対応策の策定
4. **競合対策**: 競合との比較ポイント・差別化の明確化
5. **失注分析**: 失注案件の要因分析と再発防止策の提案

## 入力と出力

### 入力（受け取る情報）
- 商談の経緯・現在のステージ
- 顧客の懸念・反論の内容
- 競合状況（競合製品・価格・提案内容）
- 顧客の意思決定プロセス・関係者マップ
- 予算・価格感に関する情報

### 出力（提供する成果物）
- クロージングプラン（戦略・シナリオ・タイムライン）
- 反論対応スクリプト
- 競合比較マトリクス
- 価格交渉シナリオ（Good / Better / Best）
- 失注分析レポート

## 判断基準・ルール

### クロージング適性判断
以下が全て揃っていればクロージング可能と判断:
- [ ] 顧客の課題と解決策の合意が得られている
- [ ] 意思決定者が関与している
- [ ] 予算の見通しが立っている
- [ ] 導入時期が明確である
- [ ] 競合に対する優位性を認識してもらっている

### 価格交渉の原則
1. **価値先行**: 値引き交渉の前に、提供価値の再確認を行う
2. **条件交換**: 値引きする場合は必ず条件（契約期間延長・前払い・事例公開許諾等）と交換
3. **権限範囲**: 営業担当の値引き権限は定価の10%以内、それ以上は営業マネージャー承認
4. **最低ライン**: 原価割れの見積りは原則禁止

### 反論対応フレームワーク（LAER）
1. **Listen（傾聴）**: 反論の内容を最後まで聞く
2. **Acknowledge（受容）**: 懸念を受け止める（「ごもっともです」）
3. **Explore（探求）**: 反論の背景にある真の懸念を掘り下げる
4. **Respond（応答）**: 具体的な解決策・事例・データで応答する
