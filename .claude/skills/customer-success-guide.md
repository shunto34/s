# カスタマーサクセスガイド

## 概要

顧客が製品・サービスを通じてビジネス成果を達成できるよう支援するための業務マニュアルです。オンボーディングから定着化、拡大までの各フェーズにおける標準プロセスを定義します。

---

## 基本原則

1. **プロアクティブ** — 問題が起きてから対応するのではなく、先回りして支援する
2. **成果志向** — 機能の使い方ではなく、ビジネス成果の達成を支援する
3. **データ活用** — ヘルススコアとデータに基づいて顧客状態を把握する
4. **長期視点** — 短期の売上ではなく、顧客のLTV最大化を目指す

---

## カスタマージャーニー

### Phase 1: オンボーディング（導入後0〜90日）

#### キックオフミーティングアジェンダ
1. プロジェクト目標の確認・成功指標の定義
2. 導入スケジュールの合意
3. ステークホルダーの特定・役割分担
4. コミュニケーションルールの設定
5. 初期設定・データ移行の計画

#### マイルストーン
| 期間 | マイルストーン | 完了基準 |
|------|-------------|---------|
| 〜2週間 | 初期設定完了 | アカウント設定・基本データ投入 |
| 〜4週間 | 基本機能の利用開始 | 主要ユーザーが日常業務で使用 |
| 〜8週間 | 定着化 | 利用率80%以上・ワークフロー統合 |
| 〜12週間 | 初期成果の確認 | KPIベースで効果を定量化 |

### Phase 2: 定着化（導入後90日〜1年）

#### ヘルススコア算出
| 指標 | 重み | 算出方法 |
|------|------|---------|
| 製品利用率 | 30% | DAU/MAU比率 |
| 機能カバレッジ | 20% | 利用機能数 / 契約機能数 |
| サポート状況 | 15% | チケット数・解決時間・満足度 |
| エンゲージメント | 15% | MTG出席率・レスポンス速度 |
| NPS/CSAT | 10% | 最新のスコア |
| 契約状況 | 10% | 更新まで残日数・支払い状況 |

#### ヘルスランク
- **Green（80〜100点）**: 健全 — 定期フォロー + 拡大機会の探索
- **Yellow（60〜79点）**: 要注意 — 課題特定 + 改善計画の立案
- **Red（60点未満）**: 危険 — 即座に介入 + エスカレーション

### Phase 3: 拡大（契約更新・アップセル・クロスセル）

#### 更新プロセス（更新90日前から開始）
| タイミング | アクション |
|-----------|----------|
| 更新90日前 | ヘルスチェック・リスク評価 |
| 更新60日前 | 更新意向の確認・提案準備 |
| 更新30日前 | 更新条件の交渉・合意 |
| 更新日 | 契約締結 |

#### アップセル・クロスセル機会の特定
- 利用上限に近づいている機能・リソース
- 未導入の関連機能への関心シグナル
- 組織拡大・新部門への展開ニーズ
- 競合サービスの併用状況

## テンプレート

### QBR（四半期ビジネスレビュー）アジェンダ
```
1. 前四半期の成果振り返り（15分）
   - KPI達成状況
   - 主な成功事例
2. 課題と改善計画（15分）
   - 未解決の課題
   - 改善アクション
3. 製品アップデート・ロードマップ共有（10分）
4. 次四半期の目標設定（15分）
5. Q&A（5分）
```

## ベストプラクティス

- オンボーディング期間中は週次でタッチポイントを設ける
- 顧客の成功事例を社内外で積極的に共有する
- CSとセールスの連携を密にし、拡大商談をスムーズに進める
- テックタッチ（自動化）とハイタッチ（人的対応）を顧客ランクに応じて使い分ける

---

## 注意事項・禁止事項

- 顧客の不満を放置しない — 24時間以内に初期対応を行う
- 解約意向の顧客に対して強引な引き止めは行わない
- 顧客情報を社内の権限のない部門に共有しない
- 競合への移行が確定した顧客にも最後まで誠実に対応する
