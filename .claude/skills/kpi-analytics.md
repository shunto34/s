# KPIアナリティクス

## 概要

組織のパフォーマンスを定量的に把握し、データに基づいた意思決定を行うためのKPI管理・分析マニュアルです。KPIの設計から計測、レポーティング、改善アクションまでの標準プロセスを定義します。

---

## 基本原則

1. **SMART原則** — KPIは Specific（具体的）、Measurable（測定可能）、Achievable（達成可能）、Relevant（関連性）、Time-bound（期限付き）で設定する
2. **因果関係の重視** — 相関ではなく因果を見極めてアクションにつなげる
3. **シンプルさ** — 追跡するKPIは部門あたり5〜7個に絞る
4. **アクショナブル** — 測定するだけでなく改善アクションにつなげる

## KPI体系

### 全社KPI
| KPI | 定義 | 計算式 | 目標頻度 |
|-----|------|--------|---------|
| ARR | 年間経常収益 | MRR × 12 | 月次 |
| MRR成長率 | 月次経常収益の成長率 | (今月MRR - 先月MRR) / 先月MRR | 月次 |
| チャーン率 | 月次解約率 | 解約MRR / 期初MRR | 月次 |
| NRR | 売上維持率 | (期初MRR + 拡大 - 縮小 - 解約) / 期初MRR | 月次 |
| CAC | 顧客獲得コスト | (営業費 + マーケ費) / 新規顧客数 | 四半期 |
| LTV | 顧客生涯価値 | 平均月額 × 平均継続月数 | 四半期 |
| LTV/CAC比 | 投資効率 | LTV / CAC | 四半期 |

### 部門別KPI

#### 営業部門
| KPI | 計算式 | ベンチマーク |
|-----|--------|------------|
| 商談化率 | SQL数 / MQL数 | 25〜30% |
| 成約率 | 成約数 / 商談数 | 20〜30% |
| 平均商談期間 | 商談日数の中央値 | 業種により異なる |
| 平均契約単価 | 総売上 / 成約数 | 前年比+10% |
| パイプラインカバレッジ | パイプライン総額 / 目標売上 | 3倍以上 |

#### マーケティング部門
| KPI | 計算式 | ベンチマーク |
|-----|--------|------------|
| MQL数 | 月間のMarketing Qualified Lead数 | 月間目標による |
| CPL | マーケ費 / リード数 | 業種平均以下 |
| コンテンツCVR | CV数 / ページビュー | 2〜5% |
| メール開封率 | 開封数 / 配信数 | 20%以上 |
| ウェビナー参加率 | 参加者 / 登録者 | 40%以上 |

#### カスタマーサクセス部門
| KPI | 計算式 | ベンチマーク |
|-----|--------|------------|
| NPS | 推奨者% - 批判者% | 50以上 |
| 更新率 | 更新顧客数 / 更新対象顧客数 | 90%以上 |
| 拡大率 | 拡大MRR / 期初MRR | 110%以上 |
| オンボーディング完了率 | 完了顧客 / 新規顧客 | 95%以上 |
| TTFV | Time to First Value（初期価値到達日数） | 30日以内 |

## 分析フレームワーク

### コホート分析
月次の契約コホートごとにリテンション率・拡大率を追跡し、トレンドの変化を検出する。

### ファネル分析
```
認知 → 興味 → 検討 → 商談 → 提案 → 交渉 → 成約
  各段階のCVRをモニタリングし、ボトルネックを特定
```

### 異常検知ルール
| 条件 | アクション |
|------|----------|
| KPIが目標値の80%未満 | イエローアラート → 原因分析 |
| KPIが目標値の60%未満 | レッドアラート → 即時対応会議 |
| 前週比20%以上の急変 | トリガーアラート → 要因調査 |

## ベストプラクティス

- KPIは「少なく、深く」追跡する — バニティメトリクスに惑わされない
- ダッシュボードはリアルタイム更新できる仕組みを構築する
- KPIレビューは週次で実施し、改善サイクルを短く保つ
- 定性情報（顧客の声、営業フィードバック）もKPIと合わせて分析する

---

## 注意事項・禁止事項

- KPIの定義を途中で変更する場合は、変更前後のデータ比較に注意する
- 目標未達の原因を個人に帰属させない — プロセスとシステムの問題として分析する
- データの改ざん・恣意的な集計は厳禁
- 機密性の高いKPIデータの社外共有は経営承認が必要
