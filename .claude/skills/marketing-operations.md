# マーケティングオペレーション

## 概要

マーケティング施策を企画から実行、効果測定まで一貫して管理するための業務マニュアルです。リード獲得、ブランド認知、コンテンツマーケティングの各領域における標準プロセスを定義します。

---

## 基本原則

1. **ファネル思考** — 認知→興味→検討→購入の各段階に適したコンテンツを提供する
2. **測定可能性** — すべての施策にKPIを設定し、効果を定量的に測定する
3. **一貫性** — ブランドガイドラインに沿った統一されたメッセージを発信する
4. **反復改善** — PDCAサイクルを短く回し、継続的に最適化する

---

## 標準プロセス

### コンテンツマーケティング

#### コンテンツ制作フロー
1. **企画**: ペルソナ × ファネルステージのマトリクスからテーマを選定
2. **構成案作成**: アウトライン・キーメッセージ・CTAを設計
3. **制作**: ライティング / デザイン / 動画制作
4. **レビュー**: 品質チェック（正確性・ブランド整合性・SEO最適化）
5. **公開**: 適切なチャネルで配信
6. **効果測定**: PV・CV・エンゲージメント率を追跡

#### コンテンツ種別と用途
| 種別 | ファネルステージ | 主な目的 |
|------|----------------|---------|
| ブログ記事 | 認知・興味 | SEO流入・ブランド認知 |
| ホワイトペーパー | 興味・検討 | リード獲得・専門性訴求 |
| 事例紹介 | 検討・購入 | 信頼構築・導入イメージ |
| ウェビナー | 興味・検討 | リード獲得・教育 |
| メールマガジン | 全ステージ | ナーチャリング・関係維持 |
| SNS投稿 | 認知 | ブランド認知・コミュニティ |

### リードジェネレーション

#### リードスコアリング基準
| 行動 | スコア |
|------|--------|
| 資料ダウンロード | +10 |
| ウェビナー参加 | +15 |
| 価格ページ閲覧 | +20 |
| デモ申込 | +30 |
| メール開封 | +2 |
| メールクリック | +5 |

#### MQL → SQL ハンドオフ基準
- スコア50点以上
- BANT情報の最低2項目が判明
- 直近30日以内にアクティビティあり

---

## ベストプラクティス

- ABテストは1変数ずつ検証し、統計的有意差を確認してから展開する
- コンテンツカレンダーは最低1ヶ月先まで計画する
- 四半期ごとにペルソナの見直しを行う
- マーケティングと営業の定例ミーティングを週次で実施する

---

## 注意事項・禁止事項

- 個人情報の取り扱いはプライバシーポリシーに厳密に従う
- 未承認のツール・サービスにリード情報をアップロードしない
- 競合のブランド名をリスティング広告のキーワードに使用する場合は法務確認必須
- 著作権のあるコンテンツを無断で使用しない
