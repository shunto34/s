# ミーティングファシリテーション

## 概要

会議を成果につなげるための設計・運営・フォローアップのマニュアルです。ムダな会議を減らし、必要な会議の生産性を最大化することを目指します。

---

## 基本原則

1. **目的明確化** — 目的のない会議は開催しない
2. **時間厳守** — 開始・終了時間を厳守する
3. **少人数精鋭** — 必要な人だけを招集する（理想は5〜7名以下）
4. **アウトプット志向** — 必ず具体的な成果物・アクションアイテムを出す

---

## 会議タイプ別ガイドライン

### 1. 定例ミーティング

#### 朝会 / デイリースタンドアップ（15分）
```
1. 昨日やったこと（各1分）
2. 今日やること（各1分）
3. ブロッカー・困りごと（該当者のみ）
```

#### 週次チームミーティング（30〜45分）
```
1. 先週のハイライト / ローライト（5分）
2. KPI確認（5分）
3. 今週の重点項目（10分）
4. 課題共有・相談（10分）
5. アクションアイテム確認（5分）
```

#### 月次オールハンズ（60分）
```
1. 経営メッセージ（10分）
2. 各部門ハイライト（20分）
3. KPI・業績共有（10分）
4. 表彰・称賛（5分）
5. Q&A（15分）
```

### 2. 意思決定会議

#### アジェンダテンプレート
```
【議題】
【背景・経緯】
【選択肢】
  A案: メリット / デメリット / コスト / リスク
  B案: メリット / デメリット / コスト / リスク
【推奨案とその理由】
【決定事項】
【ネクストアクション】担当: / 期限:
```

#### 意思決定ルール
- **コンセンサス**: 全員合意（少人数・重要度高い場合）
- **多数決**: 過半数の賛成（選択肢が明確な場合）
- **RAPID**: 推奨者→合意者→実行者→意思決定者→インプット者の役割分担

### 3. ブレインストーミング

#### 進行ルール
- 批判禁止 — アイデアの質より量を重視
- 自由奔放 — 突飛なアイデアも歓迎
- 便乗歓迎 — 他者のアイデアに乗っかってOK
- 量を追求 — まずは数を出し切る

#### 進行フロー（60分）
```
1. テーマ・制約の共有（5分）
2. 個人ワーク：アイデア出し（10分）
3. 共有・壁出し（15分）
4. グルーピング・投票（15分）
5. 上位アイデアの深掘り（10分）
6. ネクストステップ決定（5分）
```

### 4. 1on1ミーティング

#### アジェンダ（30分）
```
1. チェックイン：体調・気分（2分）
2. メンバーの話したいこと（15分）
3. マネージャーからの共有（5分）
4. 成長・キャリアの話題（5分）
5. アクションアイテム確認（3分）
```

---

## ファシリテーションテクニック

### タイムキーピング
- アジェンダの各項目に時間配分を記載
- 「残り○分です」と適宜リマインド
- 時間超過の議題は「パーキングロット」に移動

### 発言の引き出し
- 「○○さんはどう思いますか？」と指名する
- ラウンドロビン（順番に一言ずつ）で全員発言の機会を作る
- 沈黙は考えている時間 — すぐに埋めようとしない

### 議論の収束
- 「ここまでの議論をまとめると…」で要約する
- 「決定事項は○○でよろしいですか？」で合意を確認
- 未解決の課題は次回に持ち越すか担当者を決める

---

## 会議後のフォローアップ

### 議事録テンプレート
```
【会議名】
【日時】YYYY/MM/DD HH:MM〜HH:MM
【参加者】
【議題と討議内容】
【決定事項】
【アクションアイテム】
| No. | アクション | 担当 | 期限 |
【次回予定】
```

- 議事録は会議後24時間以内に共有する
- アクションアイテムは必ず担当者と期限を明記する

---

## ベストプラクティス

- 会議の冒頭で「今日のゴール」を全員で確認する
- 資料は事前共有し、会議中の資料説明は最小限にする
- 定例会議は四半期ごとに「この会議は必要か？」を見直す
- オンライン会議はカメラONを推奨（エンゲージメント向上）

---

## 注意事項・禁止事項

- 目的不明確な会議を設定しない
- 会議中に別作業をしない（マルチタスク禁止）
- 欠席者への共有を怠らない
- 機密性の高い議題は参加者を限定する
