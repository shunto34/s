# 営業プレイブック

## 概要

本マニュアルは、パートナーサクセスにおける営業活動の標準プロセスを定義します。リードの獲得から成約、そしてカスタマーサクセスへの引き継ぎまで、一貫した品質で商談を推進するためのガイドラインです。

---

## 基本原則

1. **顧客価値起点** — 製品機能ではなく、顧客の課題解決を起点に提案する
2. **データドリブン** — 感覚ではなくデータに基づいて意思決定する
3. **スピード重視** — 初回レスポンスは24時間以内、提案書は3営業日以内
4. **透明性** — 社内外を問わず、情報の非対称性を最小化する
5. **チームセリング** — 個人戦ではなくチームで勝つ

---

## 営業プロセス（7ステージ）

### Stage 1: リード獲得（Lead Generation）
- **ソース**: インバウンド（Web問い合わせ、資料DL、ウェビナー参加）/ アウトバウンド（ABM、コールド、紹介）
- **目標**: MQL（Marketing Qualified Lead）の獲得
- **担当**: マーケティング部門 → 営業部門へハンドオフ

### Stage 2: リード精査（Lead Qualification）
- **BANT基準**:
  - **Budget（予算）**: 予算枠があるか、予算確保の見込みはあるか
  - **Authority（決裁権）**: 意思決定者は誰か、決裁プロセスはどうなっているか
  - **Need（必要性）**: 具体的な課題・ニーズはあるか、緊急度はどの程度か
  - **Timeline（時期）**: 導入時期の目安はあるか、検討フェーズはどこか
- **スコアリング**: A（即商談化）/ B（育成後商談化）/ C（長期フォロー）/ D（対象外）

### Stage 3: 初回商談（Discovery）
- **目的**: 顧客の現状・課題・理想状態の把握
- **ヒアリング項目**:
  - 現在の業務フロー・使用ツール
  - 抱えている課題（定量・定性）
  - 理想の状態（KPIベース）
  - 検討の背景・きっかけ
  - 意思決定プロセス・関係者
- **成果物**: ヒアリングメモ、課題マップ

### Stage 4: 提案（Proposal）
- **提案書の構成**:
  1. エグゼクティブサマリー
  2. 顧客課題の整理
  3. ソリューション概要
  4. 導入効果（定量的ROI）
  5. 導入スケジュール
  6. 投資金額
  7. 次のステップ
- **提案書の品質チェック**:
  - [ ] 顧客固有の課題に言及しているか
  - [ ] 数値根拠があるか
  - [ ] 競合との差別化ポイントが明確か

### Stage 5: 交渉（Negotiation）
- **価格交渉の原則**:
  - 値引きの前に価値を追加する選択肢を提示
  - 値引きは必ず条件（契約期間延長、前払い等）と引き換え
  - 最終承認ラインは営業マネージャーの承認必須
- **よくある反論への対応**: 別途反論対応シートを参照

### Stage 6: クロージング（Closing）
- **合意形成の確認項目**:
  - [ ] 契約条件の最終確認
  - [ ] 導入スケジュールの合意
  - [ ] 関係者全員の承認
  - [ ] 法務レビュー完了
- **契約書類の準備**: 契約書テンプレートを使用

### Stage 7: ハンドオフ（Handoff）
- **CSチームへの引き継ぎ情報**:
  - 顧客情報・組織図
  - 商談経緯・決定要因
  - 合意した導入スケジュール
  - 顧客の期待値・KPI
  - リスク・注意事項

## テンプレート

### 商談メモテンプレート
```
【日時】YYYY/MM/DD HH:MM
【参加者】（自社）/ （顧客）
【議題】
【ヒアリング内容】
  - 現状:
  - 課題:
  - 理想:
  - 時期:
  - 予算:
  - 決裁:
【合意事項】
【ネクストアクション】担当: / 期限:
```

### 週次パイプラインレビューアジェンダ
```
1. 先週のハイライト / ローライト（5分）
2. 今週クローズ予定の案件（10分）
3. リスク案件の共有（10分）
4. 新規案件の共有（5分）
5. アクションアイテム確認（5分）
```

---

## ベストプラクティス

- 初回商談では「聞く:話す = 7:3」を意識する
- 提案前に必ず顧客の言葉でニーズを言語化し、認識を合わせる
- CRMは商談直後に更新する（翌日には記憶が薄れる）
- 失注分析を四半期ごとに実施し、パターンを特定する
- 成功事例は部門全体で共有し、再現性を高める

---

## 注意事項・禁止事項

- 顧客の個人情報を社外ツール（未承認のSaaS等）に保存しない
- 競合他社を誹謗中傷しない — ファクトベースで差別化を伝える
- 未確定の機能ロードマップを確約しない
- 値引き承認なしに価格変更を口頭で約束しない
