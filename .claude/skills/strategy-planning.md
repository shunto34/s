# 戦略プランニング

## 概要

中長期の事業戦略から短期の施策設計まで、戦略立案に必要なフレームワークとプロセスを定義する業務マニュアルです。

---

## 基本原則

1. **顧客起点** — すべての戦略は顧客の課題・ニーズから出発する
2. **選択と集中** — 「やらないこと」を明確にすることで「やること」に集中する
3. **仮説駆動** — 仮説を立て、検証し、修正するサイクルを高速で回す
4. **実行可能性** — 美しい戦略より実行できる戦略を重視する

## 戦略フレームワーク

### 1. 環境分析

#### PEST分析
| 要素 | 分析観点 |
|------|---------|
| Political（政治） | 法規制、業界規制、政策変更 |
| Economic（経済） | 景気動向、為替、金利、市場規模 |
| Social（社会） | 人口動態、ライフスタイル変化、働き方改革 |
| Technological（技術） | AI・DX動向、技術革新、特許動向 |

#### 3C分析
| 要素 | 分析項目 |
|------|---------|
| Customer（顧客） | ニーズ、購買行動、意思決定プロセス |
| Competitor（競合） | 市場シェア、強み弱み、戦略方向性 |
| Company（自社） | 経営資源、コアコンピタンス、財務状況 |

#### SWOT分析
```
          ポジティブ        ネガティブ
内部環境    Strengths         Weaknesses
外部環境    Opportunities     Threats
```

**クロスSWOT**: S×O（積極戦略）/ S×T（差別化戦略）/ W×O（改善戦略）/ W×T（防衛・撤退戦略）

### 2. 戦略立案

#### アンゾフの成長マトリクス
| | 既存製品 | 新製品 |
|---|---------|--------|
| **既存市場** | 市場浸透 | 製品開発 |
| **新市場** | 市場開拓 | 多角化 |

#### ポーターの3つの基本戦略
1. **コストリーダーシップ** — 業界最低コストで競争優位を確立
2. **差別化** — 独自の価値提供で価格競争を回避
3. **集中** — 特定セグメントに資源を集中投下

### 3. 戦略実行

#### OKRフレームワーク
```
Objective（目標）: 定性的で野心的な目標
  └ Key Result 1: 定量的な成果指標（目標値）
  └ Key Result 2: 定量的な成果指標（目標値）
  └ Key Result 3: 定量的な成果指標（目標値）
```

## 事業計画テンプレート

```
1. エグゼクティブサマリー
2. ミッション・ビジョン
3. 市場環境分析（PEST / 3C / SWOT）
4. ターゲット市場・顧客セグメント
5. 製品・サービス戦略
6. Go-to-Market戦略
7. 組織・リソース計画
8. 財務計画（P/L予測・投資計画）
9. KPI・マイルストーン
10. リスクと対策
```

---

## ベストプラクティス

- 戦略は1ページで説明できるシンプルさを目指す
- 四半期ごとに戦略の前提条件を見直す
- 施策の優先順位はインパクト × 実現可能性のマトリクスで決定する
- 戦略の浸透には「繰り返し伝える」ことが不可欠

---

## 注意事項・禁止事項

- フレームワークを埋めることが目的にならないようにする
- 机上の分析だけで完結させない — 必ず現場のインプットを得る
- 競合の機密情報を不正に入手しない
- 戦略ドキュメントの社外共有は厳禁（取締役会承認が必要な場合あり）
